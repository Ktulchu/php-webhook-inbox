# Security policy

This is an educational reference implementation, not an audited production service.

To report a security vulnerability, use GitHub's private vulnerability reporting
feature for this repository if available. Please avoid publishing exploit details
as a public issue before a maintainer can investigate.

For non-sensitive bugs, open a regular GitHub issue with reproducible steps.

The built-in PHP web server and bundled demo credentials are **for localhost only**.
Real provider payloads and production secrets must not be sent to the demo instance.
